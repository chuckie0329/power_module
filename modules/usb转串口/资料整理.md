# 选用 USB-UART：紫色 CH340E Type-C

当前选用产品尺寸图中间的紫色 CH340E 板，PCB 16×17mm、四孔 Ø2mm、5V TTL。旁边的 CH340C / CH9340C 不作为当前实物选型。板厚、插座出板量暂未实测。

- [产品尺寸](产品尺寸.png)、[产品参数](产品详情.png)：由用户原提供在 UART 文件夹的图片原样复制归档。
- 四孔实测中心距约为 12.6 × 10.3 mm，孔组距 PCB 边缘的尺寸待实物复核。
- [原厂芯片手册](CH340C、CH340E/CH340DS1.PDF)。
- HW-221 四路转换和统一供电条件。 [串口模块接线](../../docs/串口模块接线.md)

图中 +3V3 不能当作信号电平选择引脚。采用机内 5V 统一供电前，必须确认 CH340E 板的 USB VBUS 已与板上 5V 电源通路隔离。
