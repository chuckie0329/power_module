# HW-221 / TXS0108E 资料整理

[原说明书](HW-221/HW-221%20%20%20产品说明书%20%20V0.0.doc)给出 8 通道 TXS0108E，PCB 26.3×16.24mm，两个 Ø3.776mm 定位孔，中心距 20.7mm。

本文件夹的“产品详情.png / 产品尺寸.png”内容实际是 CH340 系列 USB 转串口板，不能当作 HW-221 的尺寸来源；已原样复制到 USB 目录归档。HW-221 的依据来自上述说明书最后一页的尺寸图。

项目使用 VA=3.3V、VB=5V，OE 由内部 GPIO27 控制并设下拉。接线供电前提及条件见 [新增模块方案](../../docs/串口模块接线.md)，芯片依据见 [TI 原厂手册](https://www.ti.com/lit/ds/symlink/txs0108e.pdf)。
